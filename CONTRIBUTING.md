# Contributing

Thank you for your interest in improving this small research utility.

## Proposing changes

1. Open an issue describing the bug or proposed enhancement.
2. Discuss substantial behavior changes before implementing them.
3. Add synthetic, minimal test cases to demonstrate any fix.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request explaining what changed and why.

Please keep the project simple and dependency-free unless a dependency has a clear, documented justification.

## Data and privacy

**Do not commit** private CSV files, non-public football data, API tokens, passwords, databases, paid-provider exports, or files copied from proprietary projects. Use invented identifiers and fictional examples.

Only submit material you own or have permission to contribute. Respect third-party licenses and data-provider terms.

## Security reports

Do not post real credentials or sensitive datasets in a public issue. If a vulnerability includes sensitive material, use a private reporting mechanism available on GitHub for this repository, or contact the maintainer using an appropriate private channel.

## Project maturity

This is an early independently maintained prototype. There is no claimed contributor community or published adoption metric.
